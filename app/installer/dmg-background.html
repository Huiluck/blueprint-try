把 Blueprint 拖进「应用程序」Drag Blueprint into Applications

第一次打开被 macOS 拦住？Blocked on first launch? See the text file →

  1. 1在「应用程序」里双击 Blueprint，弹出提示后点「完成」。
  2. 2打开「系统设置 → 隐私与安全性」，翻到下面点「仍要打开」，输入开机密码。
  3. 3如果提示「已损坏」：按 ⌘ 空格搜「终端」打开，粘贴下面这行，回车后再打开。
xattr -cr /Applications/Blueprint.app

这行只去掉「从网上下载」的标记，不改动软件。命令可以从右边的说明里复制。
