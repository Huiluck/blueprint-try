# @blueprint/skill

项目左窗的技能页。`技能页.js` 复用 `viewer/project-skills.js` 的任务类型、技能卡片、选择与操作，仅将折叠外壳换成普通容器，撤去「调整技能」入口；首次进入、切换项目和重新读取均直接显示完整列表。新建项目表单的折叠入口不受影响。

模式首位为「自定义」，点击从空白选择开始，可继续逐项勾选；移除全选、清空和恢复默认，仅在读取失败时保留重试。进入页面读取已有项目选择，模式和勾选只编辑本地草稿；底部常驻「取消／确定」直角按钮。确定后才按差额调用原项目技能接口，保存期间锁定选择；取消恢复最近保存的技能和模式。换项目丢弃未确认草稿，切换同项目页签保留草稿；已确认的写入固定项目和目标集合。保存失败重新核对已写入部分并保留草稿供重试，保留读取失败、重试与保存反馈。任务模式统一读取 `viewer/project-presets.js`，新建项目表单与本页都以「自定义」为首项，选择后从空白组合开始；新项目默认使用该空组合，本页仍读取已有项目实际保存的选择。

`生成.mjs` 按接缝检查嵌入原技能组件、预设和样式，输出 `client.js`，不直接编辑生成文件。

```sh
node blueprint/packages/skill/生成.mjs
```
