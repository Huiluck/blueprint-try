# @blueprint/roster

本包是库，提供名册（任务表，存在项目的 `系统文档/任务.db`，SQLite）、纸条（YAML）、四段节点文档、路径与读写函数，不注册工具。node 调写入接口，context 和 studio 只读；存储权威与写入约定见 [协议.md](../../../协议.md#23-节点文档)。

## 源码入口

| 入口 | 提供 |
| --- | --- |
| [src/index.js](src/index.js) 的名册纯函数 | 节点、parent、请求写入者、待做（任务表上写「登记」：上级登记着、还没派的块，10-24）／开工／完成／去掉、台（bench）、正式交回（含没验；旧记录里的验了照旧读） |
| [src/任务库.js](src/任务库.js) | 任务表的 SQLite 存储：建表、按文件身份开连接、一个事务写变了的行、转手记录（只追加）、`data_version` 认别的连接改过 |
| 同文件的节点文档函数 | 节点文档Of、读节点文档、新工作文档、局部更新请求／结构／职责／记录，`标题下沉` |
| 同文件的纸条函数 | 新纸条、回纸条、自动回纸条、作废纸条、双向没回纸条与 YAML 读写 |
| 同文件的地图函数 | 任务表：`节点总表成文` 按工作、座位、分身、任务一件一行画（挡在哪读时现算，给了读者就把别的已交回工作折成一行、别人下面的任务折成计数、已发布成果只留用途开头，协议 2.26），`重建节点总表` 写 `系统文档/任务表.md`，`给读者的任务表` 给思考开头现画；`呈现节点总表入口` 仅转换与当前名册完整匹配的机器发布行；10-24 起 dock 醒来只看自己那条线（`只看线`），10-25 起上级是 dock 的再带兄弟那一层（`兄弟层`：派它的一行、兄弟各一行、兄弟下面的折成计数），run 不给，待做在表上写「登记」 |
| [src/问答.js](src/问答.js) | 待回答问题原子读写 |
| [src/信息依赖.js](src/信息依赖.js) | 节点发布的版本成果、等待条件事实与稳定唤醒输入号 |
| [src/组织.js](src/组织.js) | 职责依赖与成果呈现；交齐汇总（只给这一圈新交回的全文，送到过的记 `reportedIn`、各留一行）和等待结果、发布写成话（`交齐汇总`、`等待事实文`、`发布文`）；可选项目根仅把文档、正式产物、发布和等待的文件入口投影为绝对路径，业务原文与持久 DTO 不变；`本阶段话` 只给开线的上级自己（十步重置 2026-10-24） |
| [src/轮次.js](src/轮次.js) | 轮是表上的数字：上级每派出一批记一轮，写在派出的那几行的 `rounds`（第几轮、怎么进来、派出时第几阶段），交回存结论快照；`第几轮`＝孩子们记过的最大轮号 |

纯函数不修改入参。项目写入通过排队；`改纸条内` 和节点文档编辑接口供已有项目队列内调用，避免重入。`编辑工作文档` 使用原生文件锁和版本检查，按最新版本局部编辑，保留其余原文；写入范围显式钉在本项目根，不落到 dsh 按服务进程目录判的默认范围，项目放在哪个存储位置都能写，指到项目外的仍被拒。

`读名册` 与 `读名册同步` 读 `系统文档/任务.db`（见协议 2.19）：每个库留一份校验过的快照，自己写完就换上新的，别的连接改过（`PRAGMA data_version`）或文件被换掉（设备号＋inode 变了）就重读；返回独立可改的 `structuredClone`。`改名册` 在项目队列里改完整本校验，一个事务写进变了的行并记转手；`落名册` 整本原样落下（测试、展示壳用），`关名册` 关连接，`转手记录Of` 读一件任务的转手。名册与 YAML 的互转（`名册成文`、`文成名册`）只做文本往返和校验，不落盘。

四段文档使用显式编号边界，返回 request、responsibility、structure、record。标记缺失或坏形状报错；请求旧导出名仍指向新版请求，不猜读旧格式。旧文档里留着的「可用性」段读时跳过、不回头改（选 32）。写结构、改职责、追加记录时用 `标题下沉` 把最高一级标题推到 ###，代码块里的不动。

核对：`node --test blueprint/packages/roster/*.test.js`，不调用模型。

run 行可带 `executor`（交给哪个外部执行者）和 `external`（外部 run 做到哪：第几次、state、进程号、上次交回、用量、额度，node 的 `外部run.js` 写）；正式交回带问题时记 `handoffQuestion`，`成果入口()` 多一行「等你定」，`重开()` 清掉。旧名册里另有含义的 `question` 照旧丢。

新分身的模型名称使用行上的 `name`，一句目标保存为 `description`；`分身显示信息` 统一投影空白与理解中的占位。`documentName` 固定文档入口，未设置的旧节点沿用原路径。
