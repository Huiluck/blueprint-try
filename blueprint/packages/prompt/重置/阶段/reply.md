# 回话（reply）

这次只需要回答：对方在问、在聊、在给意见，不需要你开工。

直接回答对方，用平常话说清你知道的和你的判断；不开工，不改节点文档。回答时发现其实要开工，用 next 写一句交接。

回完，这个节点保持原样：原来在等的接着等，等的到了照常叫醒你；原来停着的照样停着。对方要你开工、继续或改活，回一句以后用 next 交接，系统当场选好环节、把那一页放到你眼前，你在这一轮里接着做。对方给了以后要照做的安排（比如做到哪一步先停下给他看），用 node_doc 记进职责或记录，免得重建以后丢了。做到那一步，用 next 或 finish 的 ask_user 停下等他回话；他亲口跟你说过话，solo 里也停得下来。
