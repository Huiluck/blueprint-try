# 视觉素材复用：8 个亲自跑通的渠道

## 把文件取得当前项目

实测下载脚本接受 `--out`，可从只读 skill 目录调用，输出写入当前项目。`本skill目录` 替换成此次加载的 `resource-reuse` 目录。脚本用 curl 下载；图片解析用 Pillow，字体解析用 fontTools。`--out` 已用 Iconify 真实下载验证。

```bash
python3 "/本skill目录/scripts/视觉/取得视觉素材.py" --source polyhaven --out "$BLUEPRINT_PROJECT_ROOT/素材/视觉来源复验"
```

可选 source：`polyhaven`、`ambientcg`、`kenney`、`khronos`、`iconify`、`cleveland`、`googlefonts`、`nasa`。可重复 `--source` 取得多种样例。这个脚本复跑已测样例；围绕新需求找候选时使用下面的入口和结果字段。

### Poly Haven：查目录，按文件清单取得模型与材质

实跑入口是 `https://api.polyhaven.com/assets?type=all`；它返回目录，在名字、标签、分类里选资产 id。选定后查 `https://api.polyhaven.com/files/{id}`。每次 API 请求使用应用自己的 User-Agent；本次为 `BlueprintResourceReuseResearch/1.0`。[官方 API 说明](https://polyhaven.com/our-api)

- 模型：本次 `wooden_table_02`，取 `gltf["1k"].gltf` 的 URL 和整个 `include`。`include` 的键就是相对文件路径，包括 `textures/`；保持目录才能让材质连上。
- 材质：本次 `brick_wall_001`，取 `Diffuse["1k"].jpg`、`nor_gl["1k"].jpg`、`Rough["1k"].jpg`。颜色图按 sRGB，法线/粗糙度按 Non-Color 挂接，已在 Blender 实际渲染。
- 环境光：本次 `venice_sunset`，取 `hdri["1k"].hdr`。实际读为 1024×512 浮点图，采样最大 RGB 为 6464，用它照明了全部 Blender 验证场景。

文件清单同时有 `size`、`md5`；9 个本次原件的字节与 MD5 均一致。只下 glTF 主文件会缺 mesh 或贴图。高分辨率变体没有下载实测。

### ambientCG：关键词直接给下载包

本次实际查询：

```text
https://ambientcg.com/api/v2/full_json?q=bricks&type=Material&limit=3&include=downloadData%2CimageData&sort=Popular
```

从 `foundAssets[]` 的 `downloadFolders.default.downloadFiletypeCategories` 收集 `downloads[]`，取 `attribute == "1K-JPG"` 的 `downloadLink`。实取 `Bricks105_1K-JPG.zip`（4,840,980 字节），CRC 全包通过。Color 实际尺寸 1024×512，1K 是长边标签。Color、NormalGL、Roughness 已用于球体渲染；包内的 blend/tres/mtlx/usdc 预制文件没有直接导入验证。[官方接口文档](https://docs.ambientcg.com/api/v2/full_json/)

### Kenney：详情页有免费 ZIP 直链

已跑通详情页：[UI Pack](https://kenney.nl/assets/ui-pack)、[Tiny Town](https://kenney.nl/assets/tiny-town)、[Nature Kit](https://kenney.nl/assets/nature-kit)。用 HTMLParser 找 `a[id=donate-text]` 的 `href` 后即可下载，不需要操作捐赠弹窗。HTML 属性实际是单引号，简单的双引号正则会漏掉入口。直链中的目录 hash/时间值可能更新，重新从详情页取得。

三包分别为 1,229,750、182,243、10,537,521 字节；ZIP CRC 均通过。UI 包 870 个 PNG + 434 个 SVG；Tiny Town 136 个 PNG；Nature Kit 329 个 GLB + 1640 个 PNG 均已解析。具体用于引擎验证的是蓝色按钮 PNG、`tilemap_packed.png` 和 `tree_oak.glb`。橡树也已 Blender 渲染。包内 FBX/OBJ/DAE/STL、音效和内置字体没有逐一导入。

### Khronos：小体积 GLB 携带可运行的骨骼动画

确切实测 URL：

```text
https://raw.githubusercontent.com/KhronosGroup/glTF-Sample-Assets/main/Models/Fox/glTF-Binary/Fox.glb
```

Fox.glb 为 162,852 字节，材质纹理内嵌。Godot 导入得到 1 mesh、1 skeleton 和 Run/Survey/Walk，时长分别约 1.158、3.417、0.708 秒。Blender 对 Run 的 0/13 帧求值，顶点最大移动 84.898 源单位；两帧渲染也有可见姿态差异。模型包围盒约 41×142×76 源单位，放入场景时适配尺寸。

官方仓库用途和模型 README 在 [Fox 目录](https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/Fox)。本次只验证它的 glTF 核心特性。REST 查询仓库提交曾遇到匿名额度耗尽的 403；取得此文件直接走官方 raw 路径，不依赖 REST 查询。`main` 会变，本次内容由 SHA256 留证。

### Iconify：带数值尺寸的 SVG 可进入引擎

实跑检索：`https://api.iconify.design/search?query=gamepad&limit=32`，返回 `icons[]` 的 `prefix:name`。本次选 `mdi:gamepad`，文件地址为：

```text
https://api.iconify.design/mdi/gamepad.svg?color=%2393c5fd&height=64
```

SVG 为 197 字节，保留矢量轮廓和 viewBox。默认导出是 `1em×1em`，首次 Godot 导入只得 1×1；加 `height=64` 后已复验为 64×64。网页渲染和引擎导入在这里有真实差别。[官方 SVG API](https://iconify.design/docs/api/svg.html)

### Cleveland：取得 print 变体，保留真实尺寸

实跑查询：

```text
https://openaccess-api.clevelandart.org/api/artworks/?q=landscape&has_image=1&cc0=1&limit=3
```

从 `data[].images.print.url` 下载。本次《Virgin and Child in a Landscape》为 1536×1931 JPEG；实际 2,643,198 字节，API 的 filesize 是 2,639,784。已完整解码，所以把这个差异记录为元数据尺寸偏差。`web`、`print`、`full` 是不同变体；本次没有下载 full TIFF。[官方 API](https://openaccess-api.clevelandart.org/)

### Google Fonts：下载字体文件再绘制中文

确切实测 URL：

```text
https://raw.githubusercontent.com/google/fonts/main/ofl/notosanssc/NotoSansSC%5Bwght%5D.ttf
```

Noto Sans SC 变量 TTF 为 17,772,300 字节；fontTools 能读取 31036 glyphs，“素材复用”都有字形。Pillow 用 400 字重实际绘制了中文预览；Godot 可以作为 FontFile 载入，中文字符串测宽为正。变量字体默认轴是 100（Thin），按应用需要选择字重。本次未依赖 Google Fonts CSS 远程字体。[官方字体文件仓库](https://github.com/google/fonts/tree/main/ofl/notosanssc)

### NASA：检索与原件清单分两步

实跑搜索 `https://images-api.nasa.gov/search?q=apollo%20moon&media_type=image&page_size=3`。取候选 `data[0].nasa_id`，再查 `https://images-api.nasa.gov/asset/{nasa_id}`，在 `collection.items[].href` 里选带 `~orig` 的图片，改用 HTTPS。

本次为 Apollo 14 Moon Tree，ID `jsc2026e396708`，实际原图 URL：

```text
https://images-assets.nasa.gov/image/jsc2026e396708/jsc2026e396708~orig.jpg
```

原图 5307×7961、7,430,653 字节，完整 JPEG 解码并成功导入 Godot。搜索 `links` 给的是预览入口，取原图用 `/asset` 的清单。这里仅验证图片方法，未验证视频、音频与字幕。[官方 API 文档](https://images.nasa.gov/docs/images.nasa.gov_api_docs.pdf)


## 已验证的使用范围

Blender 5.1.2 的五项模型/材质/环境渲染与 Fox Run 顶点变形通过，实际图像已经查看。Godot 4.7.2 的 11 个资源导入和数据读取通过；Godot 画面渲染未测。Pillow 11.3.0 / fontTools 4.60.1 用于图片与字体解析；取得脚本的 `--out` 与失败退出码也已验证。
