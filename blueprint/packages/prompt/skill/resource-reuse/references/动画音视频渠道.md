# 动画与音视频：实测取得与复用

让 Blueprint 取得可用的真实文件。按作品需要选素材，再检查目标片段、目标人物或目标运行环境是否适合。下列八条取得路线均在 2026-10-08 实际下载，并用最终 `取得素材.py` 重新运行；10 个原件的 SHA256 与首次取得一致。测试情境未开展版权审查，来源和原包附带信息仍保留。

## 先选渠道

| 需要 | 优先入口 | 已取得与检验 | 使用边界 |
|---|---|---|---|
| 游戏/应用 UI 音效 | [Kenney UI Audio](https://kenney.nl/assets/ui-audio) | ZIP、51 个独立 OGG、1 个预览；全部解码 | 即用 OGG；官网数量标注 50，实际包是 51 个 Audio 文件 |
| 写实、转场、环境和提示音 | [Mixkit Sound Effects](https://mixkit.co/free-sound-effects/) | 样例 WAV 完整解码 | 音效预览 MP3 与原件 WAV 分开 |
| 整曲视频配乐 | [Mixkit Music](https://mixkit.co/free-stock-music/) | 115 秒、320 kbps MP3 完整解码 | 这首下载与播放器 URL 相同；其他来源不能照推 |
| 写实 B-roll / 背景视频 | [Mixkit Video 样例](https://mixkit.co/free-stock-video/couple-exploring-a-forest-43151/) | Full HD 原件完整解码、查看实际帧 | 实测 1080p；720p/4K 只看见选项，未下载验证 |
| 人形基础移动、idle、战斗和交互动作 | [Quaternius Universal Animation Library](https://quaternius.itch.io/universal-animation-library) | 免费 Standard ZIP；GLB 结构检查、Blender 导入与动作采样 | 免费是 43 个 animation（含 A_TPose）；不是网页介绍的完整 120+；目标人物重定向仍需验证 |
| 网页/应用矢量小动画 | [Airbnb lottie-web 官方示例](https://github.com/airbnb/lottie-web/tree/master/test/animations) | JSON + 同版本播放器；实际 Web SVG 渲染与非空帧差 | 本次实测 starfish；移动端和 AE 编辑未测 |
| 复古游戏音效和参数源文件 | [OpenGameArt / rubberduck](https://opengameart.org/content/50-cc0-retro-synth-sfx) | 50 个 OGG 全解码，50 个 XPF XML 解析 | OGG 即用；LMMS 导入/编辑未测 |
| 原始真实动作数据 | [CMU Subject 02](https://mocap.cs.cmu.edu/search.php?subjectnumber=02) | 匹配的 ASF + AMC；骨架和全部帧解析 | 进阶源数据；未验证导入、转换或重定向，不能当即插即用动作包 |

这些检查证明已列出的取得与技术路径。音频尚未做主观试听，完整解码不能替代节奏、尾音、循环接缝和混音判断。动画也不能仅凭格式兼容就保证对目标人物合适。

## 在项目里取得文件

`取得素材.py` 只用 Python 标准库，无账号和 API key。它支持明确的项目输出目录，默认写项目根的 `素材/动画音视频`；不会把素材写进只读 skill 目录。`本skill目录` 替换成此次加载的 `resource-reuse` 目录；以下命令从当前项目调用。

```bash
python3 "/本skill目录/scripts/动画音视频/取得素材.py" kenney-ui-audio --output-dir "$BLUEPRINT_PROJECT_ROOT/素材/界面音效"
python3 "/本skill目录/scripts/动画音视频/取得素材.py" mixkit-sfx --output-dir "$BLUEPRINT_PROJECT_ROOT/素材/音效"
python3 "/本skill目录/scripts/动画音视频/取得素材.py" mixkit-music --output-dir "$BLUEPRINT_PROJECT_ROOT/素材/音乐"
python3 "/本skill目录/scripts/动画音视频/取得素材.py" mixkit-video --output-dir "$BLUEPRINT_PROJECT_ROOT/素材/视频"
python3 "/本skill目录/scripts/动画音视频/取得素材.py" quaternius-animation --output-dir "$BLUEPRINT_PROJECT_ROOT/素材/人物动作"
python3 "/本skill目录/scripts/动画音视频/取得素材.py" lottie-starfish --output-dir "$BLUEPRINT_PROJECT_ROOT/素材/网页动画"
python3 "/本skill目录/scripts/动画音视频/取得素材.py" opengameart-retro-synth --output-dir "$BLUEPRINT_PROJECT_ROOT/素材/复古音效"
python3 "/本skill目录/scripts/动画音视频/取得素材.py" cmu-walk --output-dir "$BLUEPRINT_PROJECT_ROOT/素材/动作源数据"
```

八个名字对应已实测样例。脚本附带 `--item-id`（Mixkit 音乐/音效）和 `--page-url`（Mixkit 视频）供当前页面选材后使用；具体其他条目仍需取得文件和检查，不把这次样例验证扩成全站保证。每次取得会在输出目录写 `取得记录.json`，含请求 URL、最终文件 URL、文件大小和 SHA256。

检索得到 itch 作者素材页后，可用 `itch-free-package` 取得页面明确列出的免费文件。`--filename` 必须是原包完整文件名，helper 只匹配匿名免费页的同名下载按钮。本轮除 Quaternius Standard 外，还实测 WangleLine 的下列原包：13,048,375 bytes，ZIP CRC 通过，10 个 FLAC 全部完整解码；2026-10-16 又取得 oleekconder 的 Hand painted - Parallax Forest 1（`YogeParallaxForest1.zip`，16,671,043 bytes，ZIP CRC 通过，7 张 PNG）。文件名在公开素材页的下载区就列着；填错时报错会列出免费页实有的文件名。其他 itch 页面与文件仍需检查当前取得条件及实际内容。

```bash
python3 "/本skill目录/scripts/动画音视频/取得素材.py" itch-free-package --page-url "https://wangleline.itch.io/shorts-computer-case-carnage" --filename "WangleLine - Computer Case Carnage.zip" --output-dir "$BLUEPRINT_PROJECT_ROOT/素材/金属撞击"
```

## 取得路线与实际结果

**Kenney。** GET 素材页，读取 “Continue without donating” 的 ZIP `href`，再 GET 原包。当前 HTML 的链接用单引号，helper 同时接受两种引号。原包 411,949 bytes，ZIP CRC 通过；51 个 `Audio/*.ogg` 和 `Preview.ogg` 共 52 个音频完整解码通过。大合集销售入口与单包免费 ZIP 是两个入口。

**Mixkit 音效。** 从下载按钮的 `data-download--button-modal-url-value` 取 modal，读取 `data-download--modal-url-value`，再取得原件。样例 ID 213 是 **Arcade retro game over**，取得 `213.wav`：294,730 bytes、PCM S16LE、44100 Hz、双声道、1.666667 秒。播放器的 `213-preview.mp3` 是试听，这次没有用它冒充原件。初步搜索引擎文本会随缓存与排序变化，标题以本次实际读取页面和 item ID 为准。

**Mixkit 音乐。** 同样通过下载 modal 取 URL。ID 738 是 Lily J 的 **Hip Hop 02**：4,600,684 bytes、115.0171 秒、44100 Hz、双声道、320 kbps MP3；全曲解码通过。这首的下载与播放器共用同一完整 MP3，区别来自下载动作和实际时长核对。

**Mixkit 视频。** 读取详情页 Full HD radio 的 `value`，实测为 `/free-stock-video/download/43151/?context=sidebar&type=1080p`；GET modal，再读取实际 MP4 URL。取得 **Couple exploring a forest**：49,932,368 bytes、H.264、1920×1080、24000/1001 fps、15.306958 秒、无音轨。完整解码通过，第 5 秒抽帧可见两位徒步者穿行树林。

**Quaternius。** 官网指向 itch。用同一匿名 CookieJar：GET `/purchase` 取 CSRF；POST `/download_url`；GET 返回的免费页；匹配 `Universal Animation Library[Standard].zip` 的 `data-upload_id`，用该页 CSRF POST `/file/<upload_id>?source=game_download`；GET 返回的签名 ZIP URL。签名链接会过期，重复取得时重新生成；不拼接自造 `key`。免费包 15,904,933 bytes，含 Unity FBX 与 Unreal-Godot GLB，各有普通版和 `_RM` 版。两个 GLB 均有 65 joints、43 animation；普通 GLB 在 Blender 5.1.2 导入为 1 armature、65 骨骼、2 mesh、43 action。11 个 walk/idle action 的起点与中间帧有 52 或 64 根骨骼矩阵变化。包内 README 说明 `_RM` 烘焙 root motion，另一个关闭 root motion；这项语义未在目标人物或引擎中验证。FBX、RM 的 Blender 导入、Godot/Unity/Unreal 导入和目标人物重定向均未测。`.blend` 属付费 Source；Pro/Source 不当免费包。

**Lottie。** 从官方仓库读 commit 与路径，使用 raw URL 取得 JSON 和同版本播放器。实测固定 commit `bede03d25d232826e0c9dca1733d542d8a7754fb`。`starfish.json` 24,780 bytes，800×600、60 fps、301 帧、15 layers、1 asset，无外链图片；播放器 625,450 bytes。在本地无界面 Chromium 用 Web SVG renderer 加载，frame 90/150/200 均有可见黄色海星、无 page error、实际像素各不相同。前 0/30 帧角色在画面外，不能仅凭 SVG 节点存在判定画面可用。独立证据包的 `Lottie实测预览.html` 和 `Lottie渲染验证.cjs` 保存本次具体加载方法。

**OpenGameArt。** 读取 `File(s)` 的 ZIP 链接，直接 GET；页面上有登录框不代表下载需要登录。取得 rubberduck 的 `50-CC0-retro-synth-SFX.zip`：1,938,142 bytes、101 个 ZIP 条目，50 个 OGG 全部解码通过，`source/` 下 50 个 XPF XML 解析通过。XPF 是 LMMS 参数源文件；本机没有 LMMS，未检验导入和修改声音。

**CMU。** 从同一 subject 页面同时取 `.asf` 骨架与 `.amc` 动作。实测 Subject 02 / Motion 01 的 walk，骨架 7,268 bytes、动作 273,444 bytes：ASF 1.10、30 个骨骼，AMC 343 帧、29 轨道/帧、27 条轨道发生变化；每帧参数数量与骨骼自由度匹配。该行官网标 120 fps。未验证 ASF/AMC 转 BVH/GLB、进入 Blender 或普通引擎、或映射到其他人物。如果作品需要容易搬用的人物动作，优先 Quaternius；CMU 交给已经有 mocap 导入 context 的节点。

## 检查取得的文件

音视频的技术检查命令已经实际运行：

```bash
ffprobe -v error -show_format -show_streams -of json 素材文件
ffmpeg -v error -nostdin -i 素材文件 -f null -
```

完整原件、复跑哈希比对、动作采样及 Lottie 画面证据保存在仓库 `草稿/素材渠道实测/动画音视频/`。音频已做完整解码，未做主观试听与项目混音判断。
