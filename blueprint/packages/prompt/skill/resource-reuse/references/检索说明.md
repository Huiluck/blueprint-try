# 从当前需求找到具体候选

`scripts/搜.mjs` 查询素材站当前目录；`scripts/查渠道.mjs` 查询本地实测方法。程序、引擎、完整工程与未接入站内搜索的来源，按对应渠道指南取得。

## 查询条件

```bash
node "<本技能目录>/scripts/搜.mjs" --kind 3d --source polyhaven --json "wooden table 木桌"
node "<本技能目录>/scripts/搜.mjs" --kind music --source commons --min-duration 30 --max-duration 300 --json "ambient 氛围"
node "<本技能目录>/scripts/搜.mjs" --kind sfx --source itch --max-duration 3 --json "metal impact 金属撞击"
```

- `--kind`：`2d`、`3d`、`texture`、`hdri`、`icon`、`photo`、`illustration`、`artwork`、`music`、`sfx`。不填时查支持这些类型的来源。
- `--source`：只查某站。匿名来源为 `polyhaven`、`ambientcg`、`iconify`、`itch`、`sketchfab`、`commons`、`cleveland`；`wikimedia` 也对应 Commons。不填时各站并行查；未配置凭据的来源不加入默认查询。
- `--min-duration`、`--max-duration`：秒数，只筛声音。未知时长的包继续返回并注明尚未核实；环境声归音效，音乐循环归音乐，时长不替它们分类。
- `--json`：可保存候选清单。每站最多展示六条，含来源、页面、作者、已有许可、试听、文件地址与取得状态；`候选` 给候选单和声音试听页的路径；`总览` 给总览图路径、图中编号对应的候选，以及无缩略图、缩略图取不到的编号，声音候选不进总览；单站失败在“没回”列出，其余站继续。没有结果与请求失败分别报告。
- 默认不按许可过滤。用户明确要求发布或盈利时，`--license-check` 筛已标为不可商用的候选，并在声音中筛 ND；该模式的 `--noncommercial` 保留非商业发布候选。具体适用条件按作品用途判断。

音乐用情绪、能量、曲风、乐器、人声或循环等词逐步收窄；音效用声源与动作，再加材质、空间、距离等听感特征。中文与英文一起写，英文递给各站，中文另递给 Commons。itch 的标签检索会标明实际用了什么标签。

## 当前来源与真实取得条件

| 来源 | 提供什么 | 取得与使用范围 |
|---|---|---|
| Poly Haven | 模型、PBR、HDRI 及 1K 文件清单 | 模型返回 glTF 与全部依赖，相对路径一起保存；已取得样例并做 Blender/Godot 验证 |
| ambientCG | 材质候选和包地址 | 已取得、解析和渲染 Bricks105 样例 |
| Iconify | 图标候选及 SVG 地址 | 明确数值尺寸，便于引擎导入；已实测 64×64 |
| Cleveland | 艺术图片 | 查询返回 print 优先的图片地址，web 用于缩略图；已测图片完整解码与导入 |
| Commons | 图片、录音、许可及文件地址 | 图片适配器返回 1280 宽变体；已实测缩图下载与解码。原图与录音 CDN 本轮曾 429，候选链接不表示原件已取得 |
| itch | 免费素材包页面与封面缩略图 | 已测视觉/声音标签检索与页面；选包后用 `取得.mjs --pick` 加 `--filename` 取免费页列出的文件（内部走 `取得素材.py itch-free-package`）。Quaternius、WangleLine 声音包和一个手绘视差背景包已取得原件 |
| Sketchfab | 标为可下载的模型页面 | 匿名检索已测；下载需要登录令牌，本轮未取得原件 |

搜索和下载状态分别看。挑定的候选按主入口的 `取得.mjs --pick` 照序号下载，来源记录自动写；glTF 等多文件资源按清单里的相对路径摆进目标文件夹。只有页面的继续查当前页面；确实受到登录、购买或授权阻碍时交回具体入口和未取得状态。

音频的试听与原件分列。结合实际片段判断起落、尾音、噪声、循环接缝和对白遮挡；未试听不报告听感已经成立，完整解码也不代替混音判断。

## 保留的凭据来源

旧工具的 Freesound、Jamendo 适配器保留为可选检索部件。`--source freesound` 读取 `FREESOUND_API_KEY`；`--source jamendo` 读取 `JAMENDO_CLIENT_ID`。显式选择它们时兼容 `~/.zshrc` 的简单 export 行；未配置时明确失败。**本轮只验证缺凭据分支和模拟响应，带凭据的真实成功请求没有验证，不纳入实测推荐路线。**

Freesound 的转码试听与 OAuth 原件分开，Jamendo 只有 `audiodownload_allowed=true` 才给下载文件；其它情况只返回试听或页面。两者仍保留原有类型、时长和来源信息处理。[Freesound 官方接口](https://freesound.org/docs/api/resources_apiv2.html)、[Jamendo 官方接口](https://developer.jamendo.com/v3.0/tracks)。

Openverse 原适配器未启用且曾持续超时，本轮不接入检索。旧 skill 的独立入口已合入 `resource-reuse`；搜索部件随此目录携带，声音检索不再依赖另一个 skill 目录。
