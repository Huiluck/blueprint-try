## 在 Blueprint 的当前项目中取用

下载、解压和安装目录放当前项目。下面的命令已按所用方法实测；已有同版本引擎时直接复用。研究目录及 skill 可以作为只读来源，把需要修改的源码和配置复制到项目后继续。

### Godot 官方工程：按需取得，而非下载整库

```sh
git clone --depth 1 --filter=blob:none --sparse --branch 4.7-6ad6167 https://github.com/godotengine/godot-demo-projects.git godot-reusable-demos
git -C godot-reusable-demos sparse-checkout set 2d/platformer 2d/particles 3d/platformer
git -C godot-reusable-demos rev-parse HEAD
godot --headless --path godot-reusable-demos/2d/particles --editor --import
godot --headless --path godot-reusable-demos/2d/particles --quit-after 120
```

实测取得 284 个源码/资源文件、7,380,216 字节（约 7.4 MB）；包含 Git 元数据的目录约 13 MB。与固定 commit 的整库 ZIP 中对应文件逐字节一致。完整工程入口是各目录的 `project.godot`，目录间是独立项目。运行时用了现有 `Godot 4.7.2.stable.official.ed1daf0bf`，没有另装引擎。默认 `master` 面向开发版，不等于固定稳定样例。[官方版本说明](https://github.com/godotengine/godot-demo-projects#godot-versions)

### Kenney 完整工程

```sh
curl -fLsS https://codeload.github.com/KenneyNL/Starter-Kit-3D-Platformer/zip/3fa8a04b1c01ab23db43123d4ce814a34c3fc7f0 -o Kenney-3D-Platformer.zip
unzip Kenney-3D-Platformer.zip -d kenney-game-project
```

项目根目录含 `project.godot`、`scenes/main.tscn`、`scripts/player.gd`、`scripts/view.gd`、模型、精灵、字体与声音。可直接从整个工程开始，也可复用角色控制/相机代码。源工程依赖 Godot 4.6 的 Jolt Physics 配置；本次在现有 4.7.2 运行通过。完整项目需要一起复制依赖资源，单独取 `player.gd` 会缺少其场景节点、Input Map 和 Audio autoload。

### Three.js：示例源码、运行包和资源同版本

固定源码：

- 立方体：`https://raw.githubusercontent.com/mrdoob/three.js/r180/examples/webgl_geometry_cube.html`
- 完整 lava shader：`https://raw.githubusercontent.com/mrdoob/three.js/r180/examples/webgl_shader_lava.html`
- 立方体纹理：`https://raw.githubusercontent.com/mrdoob/three.js/r180/examples/textures/crate.gif`
- lava 纹理：同目录 `textures/lava/cloud.png`、`textures/lava/lavatile.jpg`
- 公共 CSS：同目录 `main.css`
- 引擎原包：`https://registry.npmjs.org/three/-/three-0.180.0.tgz`

源码保留完整 GLSL、材质设置、时间动画和 Bloom 后期。npm 包自带 `examples/jsm/` addons，取它即可满足 lava 的 EffectComposer、RenderPass、BloomPass、OutputPass。运行 HTML 的 importmap 要映射到当前项目实际的 `three/build/three.module.js` 和 `three/examples/jsm/`，纹理路径保持相对结构。本次运行副本只改了这些定位并加入计数探针，原件保留。

### Phaser：含素材的完整游戏 ZIP

```sh
curl -fLsS https://cdn.phaser.io/tutorials/making-your-first-phaser-3-game/phaser3-tutorial-src.zip -o Phaser3-FirstGame-Tutorial.zip
unzip Phaser3-FirstGame-Tutorial.zip -d phaser-first-game
```

ZIP 有 `part1.html` 至 `part10.html` 和全部 5 张 PNG 素材；`part10.html` 是完整小游戏。原件引用在线 `phaser@3.11.0`，本次运行副本改为本地已安装 `phaser@3.90.0/dist/phaser.js` 并验证兼容。无需每次运行从 CDN 取引擎。当前 examples 仓库 master 的说明是 Phaser 4 dev，不能据仓库名称把其代码当作 Phaser 3 的稳定样例。[官方仓库说明](https://github.com/phaserjs/examples#dev-version-vs-release-version)

### Babylon：直接取固定 Playground 版本的代码

```sh
curl -fLsS https://snippet.babylonjs.com/2KRNG9/2150 -o Babylon-Playground-2KRNG9-2150.json
```

响应中的 `jsonPayload` 是 JSON 字符串，解析后取 `code` 即现成 `createScene`；此样例中代码字符串还包含字面 `\n` 和 `\"`，解开后再放入 JavaScript。运行包是 `https://registry.npmjs.org/babylonjs/-/babylonjs-8.32.0.tgz`。本地创建 canvas 和 Engine 后执行保存的 `createScene`，进入 `engine.runRenderLoop(()=>scene.render())`；样例无需额外远程素材。本次只验证该固定 snippet 的 API 获取与渲染，不把其它 Playground 的资产依赖算作已检验。

### shadcn：直接取源码或结构化 Registry

固定、可复跑的入口：

- TSX：`https://raw.githubusercontent.com/shadcn-ui/ui/c8c4027b6b192822ea2952b225ee4760cddedf0d/apps/www/registry/new-york/ui/accordion.tsx`
- JSON：`https://raw.githubusercontent.com/shadcn-ui/ui/c8c4027b6b192822ea2952b225ee4760cddedf0d/apps/www/public/r/styles/new-york/accordion.json`
- 在线 registry：`https://ui.shadcn.com/r/styles/new-york/accordion.json`，已实际请求，但内容会更新；本次快照 SHA256 可查清单。

JSON 的 `files[].content` 给完整源码，`dependencies` 和 `tailwind.config` 给依赖与动画信息。已测组合是 React/ReactDOM `19.1.0`、`@radix-ui/react-accordion@1.2.11`、`lucide-react@0.468.0`、`clsx@2.1.1`、`tailwind-merge@3.3.1`，由 esbuild `0.25.9` 与 Tailwind CLI `4.1.13` 编译。源码依赖 `@/lib/utils` 的 `cn`，运行样例提供了该文件和 alias；复制组件时一起承接。此次验证的是 Radix 版本，当前官网也有其它组件后端，参数不能混用。

### npm 与 PyPI：拿现成能力的匿名分发渠道

本 skill 的 `assets/程序依赖/package.json` 和 `package-lock.json` 保存了实测样例的全部固定版本与精确下载 URL。将两文件复制到当前项目的独立运行目录，再在那里运行本次实测的安装命令：

```sh
npm install --ignore-scripts --no-audit --no-fund
```

单个完整原包也已直接下载并保存，例如：

```sh
curl -fLsS https://registry.npmjs.org/cannon-es/-/cannon-es-0.20.0.tgz -o cannon-es-0.20.0.tgz
curl -fLsS https://registry.npmjs.org/lucide-react/-/lucide-react-0.468.0.tgz -o lucide-react-0.468.0.tgz
```

Trimesh 的实测安装在独立 Python venv，固定版不随当前最新版的 Python 要求变化：

```sh
python3 -m venv python-mesh-tools
python-mesh-tools/bin/python -m pip install --disable-pip-version-check trimesh==4.8.3 numpy==2.0.2
```

PyPI JSON `https://pypi.org/pypi/trimesh/4.8.3/json` 的 `urls[]` 给 wheel 文件名、SHA256 和 `files.pythonhosted.org` 直链；本次已直接取得 wheel，并独立执行 GLB 导出/导入程序。留存的 NumPy wheel 是 Python 3.9 / macOS ARM64 专用，其它平台用相同固定版本让 pip 选择匹配 wheel。
