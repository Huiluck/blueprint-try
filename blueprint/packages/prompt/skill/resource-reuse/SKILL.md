# 找到并取得能接着用的现成资源

围绕当前问题找到已有资源与资料。预测取信息时，了解候选、适用条件与已有经验，为估计工作量和安排分工提供依据；执行取材时，取得合适的原件、代码或工程，判断实际效果与剩余适配工作。这里提供跨站检索与已实测的取得方法。

取素材按 看 → 挑 → 取 → 用时再验：先看总览图、试听页挑，只下载挑定的；来源记录由取得脚本写；解码、透明底、循环接缝这些检查留给真要进作品的那几件，接进作品时再做。脚本用本 skill 的绝对路径调用，输入与输出相对命令当前工作目录。候选先放在临时目录，选定要共享的用 shelve 上架到项目素材，`*.来源.json` 一起保留。

按具体需求查当前素材候选：

```bash
node "<本技能目录>/scripts/搜.mjs" --kind 3d "wooden table 木桌"
node "<本技能目录>/scripts/搜.mjs" --kind music "ambient piano 氛围钢琴"
node "<本技能目录>/scripts/搜.mjs" --kind sfx --max-duration 3 "metal impact 金属撞击"
```

每次搜索把候选存成一份带编号的候选单，路径在返回开头。视觉候选的缩略图拼成一张带编号的总览图，读这一张就能按长相淘汰；声音候选另出一张试听页，不下载就能听。听不到声音时，按时长、标签、简介挑；听感决定方向时（背景音乐、招牌音），把试听页交给用户听。英文递给各站，中文另递给支持中文的来源；itch 按标签找，短词组合更合适。类型、来源、时长、JSON 参数与来源实测范围见[检索说明](references/检索说明.md)。

挑定以后按序号取：

```bash
node "<本技能目录>/scripts/取得.mjs" --pick "<候选单>" 3 "$TMPDIR/选定/森林背景.png"
```

它从候选单拿文件地址下载，旁边写 `*.来源.json`：来源页、站、作者、许可、搜索词、实际文件地址和 SHA256，不用另记。一项几份文件的（如 glTF 连着 bin 和贴图），目标当文件夹。itch 免费包加 `--filename <页面列出的完整文件名>`；只有页面的候选，在页面上找到文件地址后加 `--url <地址>`。不在候选单里的文件用 `node "<本技能目录>/scripts/取得.mjs" <HTTPS文件网址> <目标> [来源页面]`。下载器拒绝空文件、格式不符及伪装成素材的 HTML，不覆盖同名文件，也不解压、运行下载内容。

查适合的渠道、已跑通的取得方法与使用范围：

```bash
node "<本技能目录>/scripts/查渠道.mjs" 模型
node "<本技能目录>/scripts/查渠道.mjs" --json
```

它检索本地渠道索引；具体资源的取得与复用按所需材料读指南：

- [模型、材质、HDRI、图片、图标与字体](references/视觉渠道.md)
- [动作、动画、音乐、音效与视频](references/动画音视频渠道.md)
- [程序、引擎、组件与完整工程](references/程序引擎渠道.md)

指南保留了实际跑过的取得方法、版本、样例与验证范围。预测取信息时，引用这些已有记录并说明适用范围，尚未确认的留作待验证项；运行候选工程、复跑样例和组合效果测试由承担者在执行中完成。执行取材可使用专用 helper，部分支持当前页面或条目参数；解码、导入、动画播放和工程运行的实测方法也在指南里。

确实需要登录、付款或用户授权时，交回选定页面、必要操作和未取得状态。版权按当前使用情境处理：默认测试用途不按许可筛选候选，也不另做许可核查。
