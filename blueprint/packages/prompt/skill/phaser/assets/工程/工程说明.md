# 网页游戏工程

在 Blueprint 中打开 `游戏入口.html` 即可试玩。方向键或 WASD 移动；也可点按画面指定方向、按住下方触控按钮。35 秒内碰到全部星光获胜，点击“重新开始”重开。

`游戏场景.mjs` 负责 Phaser 场景与输入，`玩法状态.mjs` 负责移动、计分和胜负，`作品样式.css` 负责网页布局。按当前作品的玩法修改这些文件；示例没有外部素材、音频或联网请求。

执行 `node 检查玩法.mjs` 检查独立状态逻辑。画面可用 Blueprint 的 `render_page` 取得。检查键盘和触控、画面以及试玩手感是不同的验证；状态逻辑通过不等于浏览器输入已验证。

`依赖/phaser/` 和 `本地依赖.json` 保存固定引擎、原始许可证、来源与文件哈希。发布或移交工程时保留整个目录。其他浏览器环境需要 HTTP(S) 加载 ES module，不依赖 `file:` 双击运行。
