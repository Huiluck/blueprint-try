# Phaser 来源与运行

浏览器引擎来自 [phaserjs/phaser](https://github.com/phaserjs/phaser)，npm `phaser@4.2.1`。只提取 `dist/phaser.min.js`、原始 `LICENSE.md` 和 `package.json`，未执行发布包脚本。完整包 SRI、每个提取文件的 SHA-256 和来源见工程的 `本地依赖.json`。示例场景、玩法逻辑与创建器为 Blueprint 新写的起点。

入口通过 Blueprint 项目预览读取本地相对 JavaScript/CSS；没有服务器、CDN、额外浏览器或宿主服务依赖。发布到其他环境时保留整个工程目录，用 HTTP(S) 服务加载 ES module，文件双击的 `file:` 模式不作为已验证入口。

引擎在浏览器运行，不需要 Node 执行 Phaser。Node 用于创建工程和独立玩法检查。创建目录必须位于当前项目；创建器只读技能资源，把可修改副本放到工程内。

示例将输入转换为独立状态逻辑，再由 Phaser 显示结果。按游戏实际机制修改状态检查；计分断言通过不能证明画面、键盘焦点或触控有效。涉及音频的作品还需按浏览器用户手势策略验证播放。
