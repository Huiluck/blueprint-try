# 2D 网页游戏

交付能实际操作、可继续修改的网页游戏及源文件。Phaser 负责场景、绘制和输入；玩法状态可独立运行，便于检查移动、计分与胜负。已有网页工程先沿用其结构。

新工程可从本技能的 `scripts/创建工程.mjs` 起步：

```bash
node "<本技能目录>/scripts/创建工程.mjs" <当前项目内的新工程目录> "<作品标题>"
```

创建器复制固定版本 Phaser 4.2.1、原始许可和来源到工程内，无需 npm 安装、构建或 CDN。入口是 `游戏入口.html`；修改 `游戏场景.mjs` 和 `玩法状态.mjs` 实现当前玩法，`node <工程目录>/检查玩法.mjs` 检查示例状态逻辑。脚本只创建新目录，不覆盖已有工程。

用 `render_page` 取得入口的真实画面，再用 `read_image` 看。画面验证与玩法验证分别回答：显示是否清楚、输入是否改变游戏状态、胜负和重开是否符合目的。现版截图工具没有自动点击或按键；状态测试不能代替用户试玩的手感，交回入口供试玩，并保留未验证项。

做光效、相机滤镜、视差、离屏渲染或测帧时间之前，先读 [references/渲染实测.md](references/渲染实测.md)：4.2.1 上哪些路实测走得通，哪些不报错却没有效果。

起点支持方向键／WASD、点按移动及触控方向按钮；这只是可修改的示例，不是每个游戏的固定设计。最终通过 `present_artifact` 交回 HTML 入口和需要继续编辑的源文件。复杂资源按任务加入项目内，许可与依赖信息见 [references/来源与运行.md](references/来源与运行.md)。
