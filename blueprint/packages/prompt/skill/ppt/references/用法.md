# 演示构建与继续编辑

命令路径中的 `<本技能目录>` 使用实际读取到的 skill 目录；材料和产物路径相对命令当前工作目录。Node 需为 22.19+ 的 22.x 或 24+；图片与图表的 Office Kit 0.21.0 和 fflate 0.8.3 已随技能提供，无需 npm 安装。

## 输入与主题

Markdown 的 `#` 是封面标题，`##` 分页，列表、表格、引用和 `<!-- 备注: ... -->` 可形成正文、表格、金句与演讲备注。精确布局用 `--slides @页面.json`：

```json
[
  {"layout":"cover","title":"项目汇报","subtitle":"本周进展"},
  {"layout":"table","title":"交付情况","rows":[["项目","结果"],["首版","已交付"]],"notes":"这里填写实际依据。"},
  {"layout":"chart","title":"交付量增长","chart":{"kind":"column","categories":["上周","本周"],"series":[{"name":"交付量","values":[3,5]}],"unit":"项"}},
  {"layout":"closing","title":"下一步行动","subtitle":"说明接下来需要的决定"}
]
```

布局包括 `cover/section/bullets/statement/quote/table/closing/image/image-left/image-right/chart`。图文页写 `image: {"src":"配图.png","fit":"contain","alt":"配图内容"}`；图表支持 `column/bar/line/pie`，数值保持有限且与类别数量一致。

用 `--list-themes` 看五套主题，用 `--brand @品牌.json` 指定单个字体名称、颜色和页脚。中文字体选择当前环境和接收方可用的字体；`--lang bilingual` 只改变播放器界面，不翻译内容。静态放映加 `--motion off`。

## 修改与撤销

`--check` 返回页面 ID、修订号及静态检查。把要改的页面写进修改文件，再使用读到的修订号；失败或冲突不会覆盖新内容：

```json
[{"slide":2,"patch":{"title":"本周已交付首版","notes":"补充这次变更的依据。"}}]
```

```bash
node "<本技能目录>/scripts/制作演示.mjs" --edit 演示/项目汇报.json --edits @页面修改.json --revision 0
node "<本技能目录>/scripts/制作演示.mjs" --undo 演示/项目汇报.json --revision 1
```

修改会同步更新 HTML、PPTX 与 JSON，工程最多保留 20 次历史；只修改本技能生成的 JSON，不导入任意外部 PPTX。默认新建文件遇重名会换后缀，显式 `--overwrite` 才覆盖。

## 实际 PPTX 渲染

可选渲染依赖固定为 `@deepseek-ai/libreoffice-kit@0.1.5`，放在命令当前目录可解析的项目 `node_modules`，不全局安装。安装前按项目已有依赖流程审查该包；本技能没有自动下载安装引擎。已备好引擎时：

```bash
node "<本技能目录>/scripts/制作演示.mjs" --render 演示/项目汇报.pptx --format both
node "<本技能目录>/scripts/制作演示.mjs" --check 演示/项目汇报.json --render-receipt 演示/项目汇报-render/render-receipt.json
```

渲染读取最终 PPTX，另存逐页 PNG、PDF 和摘要收据，不改源文稿。改稿后重新渲染；缺失引擎明确返回 `unavailable`。LibreOffice、PowerPoint 与 WPS 仍可能有字体和排版差异；渲染收据有效证明的是当前文件成功渲染，画面好坏要看实际输出。

来源与固定版本见 [来源记录](../assets/程序依赖/来源.json)。上游裸 skill 的版本与渲染依赖旧值未沿用，以本地构建器 0.9.0 和渲染适配器 0.1.5 为准。
