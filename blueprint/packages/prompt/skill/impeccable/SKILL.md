# 让设计意图在画面里成立

目标是让使用者看清重要内容、顺畅完成任务，并感受到作品应有的风格。结合用途、实际内容、已有设计和用户选择，判断当前最影响效果的部分，再设计或修改。

需要建立方向或评审整体效果时，读 [设计判断](references/设计判断.md)；需要调整排版、配色、间距或动效时，读 [细节与动效](references/细节与动效.md)。只读取眼前需要的内容，已有品牌和用户认可的设计是判断背景。

修改后看实际画面，比较阅读顺序、信息分组与使用路径是否变好。网页可用 `render_page` 取得代表尺寸的画面，再用 `read_image` 查看；交互问题结合代码和现有可用工具验证。检视发现决定下一处修改。

这份技能提炼自 Impeccable 的设计方法；资料与适配范围见 [来源](references/来源.md)。
