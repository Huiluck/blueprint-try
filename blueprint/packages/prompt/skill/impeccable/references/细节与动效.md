# 细节与动效

## 排版与空间

字体承担标题、正文、标签、数据等角色。用字号、字重、颜色和间距共同表达差别，同一角色在不同页面保持一致。字体选择考虑内容语言、产品语气和实际可用字形；中文正文与西文字体分别验证。

正文宽度与行距以实际阅读为准。西文可从约 45–75 字符的行宽试起，中文根据字形、字号和阅读场景调整。看真实长标题、数字、字体回退和放大文字的换行效果。

紧密的组内间距与较大的组间间距形成节奏。共用间距和容器规则减少局部漂移；窄屏根据内容优先级重排、换行或折叠。数学对齐之后，仍可能需要依据画面做光学调整。

## 颜色、素材与状态

颜色承担文字、表面、强调、操作或状态等语义；相同含义保持稳定。配色同时看相邻表面和真实文字：常用可读性参照是正文对比度 4.5:1、大字 3:1，还要检查焦点、禁用和错误状态。

图片要支撑内容与构图，图标的风格、粗细和视觉尺寸保持一致。等待、空内容、错误、成功和不可操作时，使用者需要知道当前发生什么，以及还能做什么。

## 动效

动效可以解释变化、引导注意、回应操作或表达作品语气。先判断需要传达的关系，再选择时间、方向、缓动与运动方式。进入通常减速停稳，退出可以加速离开；两处状态间的移动考虑连续性。

出现顺序表达重要性。让关键信息有足够停留时间，避免多个效果争夺注意；操作发生时，动效能被中断并正确进入新状态。支持减少动态效果的偏好，减弱运动后信息仍能完整呈现。

## 查看修改后的结果

挑能暴露本次问题的尺寸与内容状态，查看层级、换行、遮挡、对齐和视觉重心。涉及操作时检查相应状态与键盘焦点；涉及动效时检查开始、变化中和结束的画面。根据观察继续修正，不凭参数本身宣称效果成立。
