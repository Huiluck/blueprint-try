# 网页画面取证

调用 `render_page` 打开项目内 HTML、SVG 或 HTTP(S) 网页，取得真实画面并存入项目。例如：

```json
{"entry":"demo/index.html","width":1280,"height":800,"wait":2.5,"output":"截图/首页.png"}
```

- 项目文件使用 App 的预览服务，相对图片、样式、模块脚本和 `fetch()` 都能按网页运行。
- width、height 是视口尺寸；看手机布局可用 390 × 844。
- wait 是页面启动后等待的秒数，默认 2.5；动画或加载需要更多时间时可调大，最多 10 秒。
- 项目 HTML 登记了可定位时间轴时，用 time 指定动画秒数；未指定则取得页面当前状态。
- output 是新的项目内 PNG 路径；省略则存入“截图”。旧图保留，改版截图使用新文件名。
- 返回实际路径后用 `read_image` 查看。持续连接无需结束才截图；失败时依据实际错误判断，不把超时猜成页面错误。

检查已有画面能支持哪些判断；需要新的网页画面时再截图。App 自带截图浏览器，不需要安装 Chrome 或 Playwright，也不需要命令全权限。

需要确认改版实际改变了哪里时，用 [像素比较](references/像素比较.md) 生成变化区域和叠图。它复用当前 ImageMagick，差异比例只说明像素变化。

要登录、点击或填表的网页，以及桌面上其他程序，需查看当前能力条件。现版 App 尚未接入交互式浏览器和桌面操控；涉及这些操作时说明所需用户操作，公开页面仍可读取或截图。其他运行环境已接入相应能力时，再按可用目录选择 `playwright-cli` 或 `peekaboo`。
