# 比较两次实际画面

对改版前后或目标图与实际图使用相同尺寸。脚本把 sRGB 或透明度任一通道差异超过 2% 的像素标成红色，并保存差异比例、输入指纹、变化区域与叠图；不自动缩放，也不把差异比例当作设计质量分数。

```bash
node "<本技能目录>/scripts/比较画面.mjs" "截图/改版前.png" "截图/改版后.png" "截图/改版比较"
```

脚本位置相对本技能目录，图片和结果路径相对命令当前工作目录；调用时用脚本的绝对路径。需要 `node` 和 ImageMagick 7 的 `magick`。用 `read_image` 查看叠图，判断变化是否落在本次需要改的位置。动画、字体加载、反锯齿与素材变化也会造成差异；按实际画面判断原因。

这项能力取代另建视觉检查技能的方案，避免与网页截图、图片加工重复。参考 [DSH Vision Toolkit](https://github.com/Anionex/dsh-vision-toolkit/tree/918741f3fc204e21573db79c0bf69e6840e09827) 的像素证据思路，当前使用已有 ImageMagick，未迁入第二套图像模型和运行时。OCR 与位图矢量化暂未接入。
