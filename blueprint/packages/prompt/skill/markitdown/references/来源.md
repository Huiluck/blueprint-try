# 版本与读取边界

- MarkItDown：Microsoft 开源项目，[GitHub](https://github.com/microsoft/markitdown)，MIT。
- 实际读取版本：`markitdown[docx,xlsx,pptx]==0.1.8`，Python 3.12；脚本旁的锁文件固定传递依赖。
- 已审查的 wheel SHA-256：`de7375a50578a39bcbbf13b48c67d99033d988e0ae8ad25af46ed432dbe4cbab`。[固定 wheel 来源](https://files.pythonhosted.org/packages/33/de/0b23cd8d8955221a39438ba8e4cf583e4f510fc79c6891fff88fb3e61198/markitdown-0.1.8-py3-none-any.whl)
- 包装器只按已确认的 Office 格式调用对应本地转换器；不使用通用 URL 转换入口，不注册第三方插件、云解析或图片理解。

XLSX 提取读取工作表中的已有值，不运行 Excel、不重算公式；没有缓存的计算值可能缺失。PPTX 可以提取文字、表格、图表数据和演讲备注，不能凭提取文字判断排版。DOCX 可以保留标题、列表和表格；图片、修订和复杂版面不承诺完整还原。

初次执行需要下载 Python 和锁定依赖，只取 wheel、不运行远程构建脚本；后续复用当前项目的 uv 缓存。App 已把缓存与下载环境设在项目临时目录，按现有命令环境使用。
