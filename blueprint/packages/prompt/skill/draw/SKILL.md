# 画图

工作目标是为当前已明确需要的新图，生成符合实际用途的素材。路线选择在节点判断中完成，本 skill 负责准备、生成与检查。每次调用收费，画之前结合使用场景确定主体、构图、风格、尺寸和影响效果的关键要求，修正描述中的遗漏与冲突，尽量一次取得可用结果。

有 `media_catalog`／`media_call` 时，先从目录选择支持 `image.generate` 的服务，给出能说明图片内容的 `name`、画面描述和适合用途的尺寸，再调用取得实际文件。连接和 Key 在 API 页面管理；缺少可用服务时说明所需能力，请用户在那里添加。结果保存在本项目 `素材/AI生成/`，需要时可加工或复制到作品使用的位置。

- 尺寸、参考图和透明底按所选模型的实际能力与目录默认参数使用。硅基流动的 `Tongyi-MAI/Z-Image-Turbo` 只接受文字，默认 `image_size: "1280x1280"`；其他尺寸写成 `宽x高`，参考图编辑需选择支持它的模型，通过 `files` 或本会话 `attachments` 提供原图。
- 已返回异步任务或生成结果但下载失败时，沿用同一 `job` 查询或重试取图；提交结果不确定时先核实服务商记录，避免再次生成同一张图。
- 画完用 `read_image` 看，按实际使用尺寸与场景检查效果。需要重画时，先从上一张找准问题和原因，把相关修正一并想清楚、写进描述，注意保留已有优点，不边想边画、逐个细节反复抽图。裁切、调色、抠图或排版能解决的，优先加工；已满足用途就采用。连续重画仍没解决问题时，先重新理解问题与方法，再决定下一步。

所选模型不支持透明底、而图片要叠在别的画面上时（视差前景、角色、道具），让它画在一块纯色底上（挑画面里不会出现的颜色，比如纯品红 #FF00FF），画完用 `magick` 把那个颜色抠成透明：

```bash
magick "$BLUEPRINT_PROJECT_ROOT/素材/角色/猫.png" -fuzz 12% -transparent '#FF00FF' "$BLUEPRINT_PROJECT_ROOT/素材/角色/猫-透明.png"
```

需要可编辑文字、版面或交互界面时，沿用作品的制作方式，由负责这部分的节点处理。

旧环境没有媒体工具时，沿用硅基流动脚本入口；Key 来自该环境的 `SILICONFLOW_API_KEY`，模型与地址可由 `SILICONFLOW_IMAGE_MODEL`／`SILICONFLOW_BASE_URL` 配置：

```bash
node "<本技能目录>/scripts/画.mjs" "画面里有什么、什么风格、什么光、什么色调" "$BLUEPRINT_PROJECT_ROOT/素材/背景/夜色.png" [--尺寸 1280x1280]
```

该脚本只吃文字，尺寸每边最大 2048，1024–1536 最稳，默认 1280x1280。App 中已有媒体工具时使用 API 页面管理的服务。
