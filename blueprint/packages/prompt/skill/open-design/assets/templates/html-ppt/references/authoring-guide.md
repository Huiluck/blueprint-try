# HTML 演示制作

让每页帮助观众理解这一段的关键关系，并使整套内容适合受众、讲述时长和使用场景。当前任务已有的语言、内容、视觉选择与格式要求，作为制作背景。

从 `templates/deck.html` 建立项目内的演示；主题见 `references/themes.md`，页型见 `references/layouts.md` 和 `templates/single-page/`，整套组合见 `templates/full-decks/`。选择能表达内容关系的结构，复制相应 slide 区块并替换示例内容。

模板依赖 `assets/` 中的基础样式、字体样式、主题、运行脚本和按需使用的动画；将相关文件复制到项目，按保存位置调整 HTML 的相对引用。主题中的文字、表面、强调等视觉角色与选定设计方向一致。

给页面填写有意义的 `data-title`；需要讲稿时加入 `.notes`。中文可设置 `lang="zh-CN"`，并检查实际字形、字体加载和中英文混排。控制文字量与视觉重心，使远距离观看时仍能辨认主要内容。

动效用于揭示关系、先后或变化，相关写法见 `references/animations.md`。整套演示可以通过网页预览播放；挑关键页和关键时刻，用 Blueprint 的 `render_page` 与 `read_image` 查看实际画面。按本次内容检查文字遮挡、边界、对齐和讲述节奏。

此打包版本提供模板与网页素材，未包含上游安装和外部浏览器导出脚本。需要 PNG 可用内置截图；其他交付格式结合当前项目已有工具取得。
