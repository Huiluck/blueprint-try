# 模板使用

资源位于本 skill 的 `assets/templates/`。模板提供结构和可运行素材，内容与风格按当前任务调整。

| 任务 | 起点 | 按需参考 |
|---|---|---|
| 网页、落地页、文档或产品原型 | `web-prototype/assets/template.html` | `web-prototype/references/layouts.md`，含不同内容区块的 HTML 结构；`example.html` 可看成品关系 |
| HTML 演示文稿 | `html-ppt/templates/deck.html` | 从 `templates/single-page/` 挑页型；`templates/full-decks/` 有整套示例；按需要读 layouts、themes、animations 等资料 |
| 社交图文轮播 | `social-carousel/example.html` | 从示例提取版面尺寸、页面切换和图文关系，再换成任务内容 |

复制所需素材和相关依赖到项目，保留其相对文件关系。设计系统的 `tokens.css` 是语义样式变量资料；模板的变量名可能不同，理解文字、表面、操作和强调等角色后再映射。

HTML 演示模板连同相关 `assets/` 复制到项目，调整样式与脚本的相对引用。用已有任务情境确定内容结构和页型，需要具体制作提示时看 `html-ppt/references/authoring-guide.md`。

参考资料里出现的 OpenDesign 应用界面、专用工具或导出能力，按 Blueprint 实际工具判断。这里提供资料和模板，HTML 页面可以在项目里运行并用内置截图查看。每套系统的颜色、字体、布局和组件要配合使用；混用之前判断哪些关系需要保留。
