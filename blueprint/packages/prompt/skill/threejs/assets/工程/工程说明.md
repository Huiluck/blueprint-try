# 网页 3D 工程

在 Blueprint 中打开 `场景入口.html`，拖拽旋转镜头、滚轮缩放、点击展品或侧栏切换选择，选择配色改变当前展品。镜头复位按钮恢复初始取景。

`空间场景.mjs` 保存相机、几何、灯光与浏览器交互；`空间状态.mjs` 保存选择和配色；`作品样式.css` 保存网页布局。`展品模型.gltf` 是自有简易晶体，验证工程内 GLTFLoader 读取，可替换为当前作品的本地模型。

执行 `node 检查交互状态.mjs` 检查独立状态逻辑。WebGL、真实拖拽、选物、换色和镜头复位还需浏览器验证；Blueprint 的 `render_page` 只取得画面，不自动操作。运行需要浏览器可用的 WebGL 2。

`依赖/three/`、`本地依赖.json` 保留精确版本模块、许可证、来源与哈希。此起点支持未压缩标准 glTF/GLB；Draco、Meshopt、KTX2 解码器按所用资源另行核对。移交工程保留整个目录，其他浏览器环境通过 HTTP(S) 加载模块。
