# Three.js 来源与运行

浏览器库来自 [mrdoob/three.js](https://github.com/mrdoob/three.js)，npm `three@0.186.0`，MIT。工程保存 `build/three.module.js`、`three.core.js`，OrbitControls、GLTFLoader 及其相对模块依赖，原始 `LICENSE` 和 `package.json`。完整包 SRI、提取文件 SHA-256 和来源见工程的 `本地依赖.json`。示例、自有 glTF 和创建器为 Blueprint 新写的起点。

`场景入口.html` 的 import map 将 `three` 映射到工程内构建，并将 `three/addons/` 映射到工程内 addon。相对依赖通过 Blueprint 预览服务读取，没有 CDN、独立服务器或外部浏览器。其他环境用 HTTP(S) 服务加载 module；`file:` 双击不作为已验证入口。

起点采用 WebGLRenderer，运行需要浏览器可用的 WebGL 2；Node 仅负责创建与状态逻辑检查。GLTFLoader 支持标准 glTF/GLB；此包没有打包 Draco、Meshopt 或 KTX2 的解码器。导入带这些压缩扩展的资源时，先确认它需要的解码器，并将已核对版本的解码文件放入本工程。加载器模块自身不等于压缩资产已可加载。

自有 `展品模型.gltf` 为内嵌几何数据的简易晶体，供验证本地模型加载。载入新模型时检查实际比例、原点、材料、贴图路径和相机取景；格式可解析不能证明模型符合作品目标。
