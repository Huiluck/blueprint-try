# 时间轴与来源

独立工程使用 HyperFrames 的核心约定：根元素声明 `data-composition-id`、`data-width`、`data-height`、`data-duration`；完成的 GSAP 暂停时间轴登记在 `window.__timelines[id]`。根 id 与登记 id 相同。当前示例只有一个场景，无需 HyperFrames 工作台、CLI 或 DSH 插件。

动画初态和终态写在时间轴中，避免同一属性同时由 CSS 动画和 GSAP 改写。使用 `fromTo` 指定起止状态；不依靠当前钟表或未固定的随机数计算画面。每个字幕片段有明确的开始与结束，字幕不遮住解释对象。播放控件只控制时间，不进入画面。

`render_page.time` 对项目 HTML 中登记的时间轴定位，调用 `pause().seek(time, false)`；没有时间轴会报错。它不执行 HyperFrames 的媒体寻址、子场景装配或音频混合。需要音视频素材时可沿用当前媒体生成和 FFmpeg 加工能力，但成片导出须实际接通渲染后才报告。

这次保留 HTML 动画一个入口，取代旧 Explainroo 的制作入口。旧工具链依赖外部 Chromium、语音模型和对齐依赖，当前 App 不能直接运行；其资料保存在调研目录，不并列交给模型试选。Remotion 与 DSH 视频工作台暂不进入技能目录。

来源：[HyperFrames 核心协议固定快照](https://github.com/heygen-com/hyperframes/blob/ba08acb1f506b06757bd77a7e7f491d412647fbd/skills/hyperframes-core/SKILL.md)。当前工程由 Blueprint 独立适配，未复制上游访谈、自动更新与审批流程；浏览器动画库为 GSAP 3.15.0，其许可和发布校验记录随工程保留。
