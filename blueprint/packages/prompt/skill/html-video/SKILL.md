# HTML 时间轴动画

让画面、字幕与讲解在观众需要它们时出现，留下可继续修改的时间轴工程。当前接入制作、播放与指定时刻的画面检查；完整 MP4 和音轨混合尚未接入。

用本技能的项目创建器取得本地 GSAP、中文示例和播放控件。脚本位置相对本 skill，产物路径相对命令当前工作目录；调用时使用脚本绝对路径：

```bash
node "<本技能目录>/scripts/创建动画.mjs" "讲解动画"
```

在项目中修改 `场景.js`、`index.html` 和 `场景.css`。旁白、字幕和画面共同围绕观众应理解的内容安排；时间轴采用秒，字幕与对应动作一起定位。工程资源放在本地，任意时刻的画面由同一条暂停时间轴确定，便于重复检查。

用内置 `render_page` 的 `time` 检查关键时刻，再用 `read_image` 查看：

```json
{"entry":"讲解动画/index.html","time":3,"width":1280,"height":720,"wait":0.2,"output":"截图/讲解动画-第三秒.png"}
```

通过 `present_artifact` 交回 HTML 播放入口与工程。关键帧说明布局与状态，实际播放判断节奏；不能把 HTML 或关键帧报告成已经生成 MP4。修改已有工程时沿用其时间轴和素材。技术约定与当前范围见 [时间轴与来源](references/时间轴与来源.md)。
