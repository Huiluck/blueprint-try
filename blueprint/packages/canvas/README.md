`画布.js` 接数据与会话导航。启动 token 在 dsh 网页入口换取同源 HttpOnly cookie；history 请求显式使用 `credentials: "same-origin"`，EventSource 使用同源 cookie。图纸使用根槽位，以免原生 `session-maybe` 在换会话时重挂载。当前会话与目录来自框架 `useSessions` 的 `retainedBy.mainView`；项目归属使用 studio 的 `projectRootSession`，目录在已有项目内时也可认领。会话未归属项目时保留空白画布，不显示归属提示。

现有 `/studio/api/history` 无 cookie 时也返回 200；本包随同源请求带上 cookie，不改变后端鉴权。

SSE 连接 `/studio/api/stream` 时不带 session 参数，接收所有节点的广播，避免只因看图把冷会话提升为活会话。项目初次进入仅请求一次 `/studio/api/history?session=…&要=树&首屏=1`，先画项目树及节点状态，细节经随后一帧 `blueprint.tree` 补入。按项目缓存最多 16 份；同项目切换保留 DOM，仅调用 `mirror.select()`。流连接属于本包，切节点不重建。`blueprint.tree` 推送服务端按原判据投影的状态；`blueprint.roster_changed` 仅在名册内容真变时触发 HTTP 重读，重连从 stream 取得树快照。服务端只读文件签与原生 persistence，不捞活节点。

图纸与看板传 `子树折叠:false`，所有节点的子树保持展开；旧的本机折叠记忆不参与显示。撤下 seat 右侧收缩通栏和普通子节点的折叠入口、计数条与占位，seat 统一宽 248px，节点保持 200px。连线直接挂实际外框；旧 Studio 未传该选项时沿原行为。

`生成.mjs` 嵌入 `viewer/mirror-render.js`、`viewer/mirror.css` 和 studio 白板令牌，输出纯 JS `client.js`。镜像样式放在 `.bpc` 的 CSS scope 内，避免通用类名影响 dsh 对话。图纸和看板都传可选 `节点样式: '顶栏右签'`，旧 Studio 不传，维持原样。看板固定四列「正在运行、等待中、待回答、已结束」，不显示未启动；完成、停止、废掉和移除汇入已结束，卡片保留原状态、颜色和操作。`看板.js` 只负责列归并与适配，不改后端状态判据。
