# @blueprint/layout

浏览器布局包，消费 dsh 的槽位、会话 hook、主题、快捷键及原生布局服务契约；提供图纸底层、对话浮窗、项目管理弹窗、全局面板浮窗和常驻工具面板。Node 半为空，不改变节点行为。

`停止快捷键.js` 在工作区支持单次 Esc 停止当前选中的运行节点，复用现有单节点停止接口，外部 run 沿 Live 的停止入口。按键时固定项目和节点身份，合并尚未完成的重复请求；空节点与座位不回退到上一个会话。弹窗、菜单、整页方案、最大化工具、终端和输入法优先保留各自的 Esc 行为，空闲节点继续沿图纸原有收起操作。

视觉（2026-10-14「精密工作台」）：冷石墨黑顶栏与反白几何字标，白色阅读面、轻灰导航、浅边与柔和阴影；当前项用浅灰底和深色图标，普通界面改用系统字体，计量与标识保留等宽。主阅读卡片使用近场、中层与远场三层阴影及稍深细边，拖动时提高阴影高度、避免内外窗壳叠加投影，收起成 B 后仍用短阴影；其他工具窗与菜单沿共享阴影。窗体和按钮保持直角矩形，输入与菜单使用 4px 小圆角，B 与两枚静态视图图形保留。竖栏与顶栏采用接近 ChatGPT 气质的常规语义图标，共用 24 格、1.75px 线宽、圆润端点与完整轮廓；竖栏显示 22px、顶栏 20px，图形保持静止。设置恢复原生齿轮，按钮和所有行为保留。`框架.js` 集中框架视觉变量，生成器通过原生主题令牌同步 dsh 组件及 body portal；`表单生成.mjs` 只在新宿主撤去旧阅读样式的零圆角重置，并适配表单外观。原几何、布局、收放时序、事件与生命周期不变，见 DESIGN_GUIDE 文首及第四、十节。

`问题恢复.js` 从 canvas 复用的 Studio SSE 取项目已保存的待处理请求，经原生 pending-interaction 和问卷 owner 恢复；问题标识由会话与持久 rpcId 组成，刷新、项目切换及宿主重启不更换草稿键。原生问卷保留选项、分页、多选和填写草稿；`问题材料.js` 为每道问题同时列出“查看材料”链接，实时与恢复卡共用。完整项目路径通过既有安全文件入口核对，短引用只匹配当前会话已有材料，重名显示各自路径、缺失明确提示；图片、视频、音频点击后在独立预览中查看，网页、PDF 和文档打开原件，关掉预览不提交回答、不清草稿。分页与切会话取消旧读取，预览关闭即停止音视频；方案审核采用同一白底细边、直角按钮；全文在工作面板内容区整页展开，正文占满剩余空间并独立滚动，审核操作固定在底部，支持返回对话和 Esc。原对话及紧凑卡占位保留，返回不改变对话位置；展开状态和修改意见仍沿原草稿恢复。只有真实提交通过原 `respond` 接口答复，不以刷新、关闭卡片、已读或挂载代替决定，不删除其他项目的草稿。

输入框上方不呈现 dsh 原生 Goal 目标栏：仅将 `conversation.input.dock` 的 `goal` 呈现置空，原登记与注入契约保留；不清除、暂停或修改 Goal，节点持续运行仍由原生 Goal 与 Blueprint 业务生命周期负责。

对话运行提示沿用 dsh 的真实运行状态、秒表及无障碍播报，显示 `thinking....` 与真实耗时；鲸尾和蓝色扫光换成 Blueprint 原有三格方块波。`运行提示.css` 只提供横排与原生装饰层适配，生成器从 `viewer/mirror.css` 提取同一份 4px、1.4s、0/.19/.38s 透明度动画；减少动态效果时显示静态 `▶`。

`框架.js` 是 Blueprint 框架。顶部「项目」左侧提供矩形「＋ 新项目」按钮，直接打开现有新建表单；再次点击保留当前草稿，窄屏保留加号入口。`生成.mjs` 从 web profile 已安装的 `@deepseek-ai/dsh-client-ui-layout/client` 按区域标记保留 store、service、theme-presenter 和 apply，替换框架并把视图与浮窗选择接入同一个 store，输出纯 JS `client.js`。图纸／看板选择不持久化，重新加载回到图纸。浮在图纸上的左窗和全局面板是磁块：抓标题栏、节点／座位铭牌或 B 方标拖动，松手吸到最近的角；B 轻点仍收放，拖动后的点击不触发收放，虚线框预示落点；朝里的两条边可拖宽高，双击恢复。角、宽、高存本机 `blueprint.tiles`。B 方标可直接拖动整个面板，轻点仍收放，超过 4px 才进入拖动，松手不触发收放；收起时用 50px 方标落点预示停靠。面板从左到右或从右到左停靠后，图纸平滑移到对应工作区，保留缩放、纵向位置与用户平移。工具改为独立常驻面板，入口放在全局顶栏右上角，依次为终端、变更、浏览器、文件夹，不保留「停靠栏」按钮和对话窗头的重复入口。上游区域或替换接缝不合时生成器报错。

`外部run页.js`、`外部run页.css`、`外部run页数据.js`：Codex／Claude Code 的 run「对话」页改为只读的任务与执行记录。先看状态、任务摘要与交回结果，再看实时产物和执行过程；Agent 说明保留 Markdown 全文，连续命令及文件操作折叠，命令输出按需展开，旧轮次与模型／额度收进详情。启动时另存任务名和目标快照，旧轮次缺失摘要时不拿当前请求重建；系统 prompt、schema、系统补文不进入阅读面。读取 `/studio/api/external-run?视图=工作`，开着时每 3 秒更新，交回后每 10 秒更新；切节点或离开页签取消旧读取。停止、重试、整理交回和交付分开呈现。底部「向…补充要求」只导航到派出节点，外部执行中不能直接追加消息。

实时产物从节点自己的 Git 工作目录相对开工起点读取，包含已提交、未提交和新文件，不只依赖工具日志。按实际大小和修改时间更新，图片直接缩略，网页／视频／音频复用 `material-preview`，点击沿原生文件入口查看当前版本。运行中标明仍在制作；目录或起点缺失时显示暂不可读取。读取不暂存、不提交、不并入，过滤隐藏配置、依赖目录和指向工作目录外的软链接。

外部节点的「文件廊」默认显示同一份实时产物，复用普通文件的 16:9 卡片、内容预览、搜索、筛选和分页。`files/文件流.js` 用项目根会话和外部节点号定位，`框架.js` 向页签传入 `active`；可见时每 3 秒更新，切节点、切页签、收起或隐藏窗口取消旧读取，恢复后读取当前内容。

`工具栏.js` 通过延后 `ctx.inject` 订阅 `sidebarRightTabs`，只显示实际登记的工具类型，不把 sidebar-right 加成 layout 的启动依赖。四个图标各自切换面板，打开时中性高亮。工具窗默认放在主窗对侧，单窗宽度沿主窗当前宽度并按剩余空间收缩；多窗先保留同样宽度，只有空间足够容纳两块原宽工具窗时才分两列，其余上下分块。`工具窗口.js` 提供四边、四角的独立缩放与标题自由移动，不吸附回角落；另一边保持固定，最小 320×160px，窄屏与矮屏以实际工作区为界。位置与大小按工具类型存本机 `blueprint.toolWindows`，收起、刷新和切项目后复用；视口收小时只约束显示，恢复后保留原偏好。八处抓手双击恢复默认位置和大小。指针捕获跨 iframe，取消手势、隐藏会话与卸载清除监听，不保存半途尺寸。每窗右上角分为减号「收起」、放大／还原和叉号「关闭全部页面」：收起只隐藏，保留挂载与原生页面记录，再打开复用已有终端、浏览器和文件预览；叉号逐页调用原生关闭，清空这块工具窗的全部页签及合并预览别名，然后隐藏窗口。页签自己的叉号仍只关闭该页。放大时 Esc 还原并保留原尺寸。隐藏偏好按会话存本机 `blueprint.workspacePanels`，各会话独立。文件树和文件预览放在同一块内，以页签切换；页签与放大／收起合成一条 40px 白底窗头，撤去重复的当前文件标题行。连续页签之间只留细竖线，当前项采用很浅的灰底、13px／600 实色名称和底部 2px 短刻线；图标以中性灰呈现，不使用反白块、独立卡框或页签阴影。文件预览的原生路径／刷新／查看方式整栏隐藏，不占位；浏览器地址栏和预览正文的加载、失败与文件变化提示保留。原生文件类型图标、浏览器实时标题和终端名称继续使用原 title 槽。单页也显示页签；切换或缩窄窗口时将选中页签滚入可见范围，支持左右键及 Home／End 切换。页签关闭调用原生清理，窗头收起只隐藏，空白区仍可拖动整窗。计划临时预览按会话和审批请求识别，合并页面重建产生的不同随机地址，优先显示当前聚焦记录；关闭该预览时逐一清理其别名，不合并其他审批或正式计划。浮窗继续显示在原停靠栏收起之后，收起仍由本机面板偏好控制；未展开的停靠页不自动转为浮窗。

页面及资源生命周期仍用 dsh。生成器从已装 sidebar-right 原样搬 `TabSlot`，只换函数名和容器类名；原生 `tabInfo`、导航、持有和 `keepMounted` 契约保留。原 `rightbar.session` 的 store、inject、会话授权及子槽保留，仅装饰窗壳；实际记录通过原生 `floatTab` 各占 pane，原生关闭页面命令仍能找到资源并做清理。slot 晚登记或重载时重接，卸载时还原。对话窗头的原生停靠栏开关以 single slot 的优先级 -1 空呈现撤下，DOM 中不留按钮。这里不显示原生 dock 的分栏、回收与整栏全屏控件，面板排布和放大由 Blueprint 窗壳负责。

变更复用 `ui-deliverables` 的 `changes-review`，选择当前会话已加载的最近一份 `workspace/changes` 记录，用原生资源地址打开逐文件对比。没有记录时提示，没有该类型时省略入口。旧停靠记录只有文件预览时，文件夹图标仍打开原生文件树。这里展示按轮保存的改动，不另实现分支间 Git 对比。

`品牌.js` 提供全局字标和左窗方标：长标直接内嵌已有 `viewer/blueprint-wordmark.svg`，保留用户 `Blueprint Logo.html` 的几何字形与构造线；方标用同文件的小尺寸 B 字形。竖排页签顶部新增方标入口，点击将整窗沿方标所在的上角缩成 50×50px 方块，再点恢复。540ms 缓出过渡窗壳宽、高与位置，内容保持原尺寸轻缩、淡出／淡入，不重排或卸载会话；收起时内容 `inert`、焦点回方标。沿用 `leftOpen`，窗头不再放重复的收起按钮；布局快捷键与图纸选节点自动展开仍共用 `leftOpen`。左右停靠均以方标的位置为锚，停靠角及完整尺寸仍由原磁块保存；支持快速反向点击和 `prefers-reduced-motion`。

图纸／看板切换入口改为 B 方标旁的两枚 50px 工业线条按钮，全局顶栏原文字按钮撤掉。`BlueprintViewIcon` 用原生 SVG 画图纸的导轨与节点连线；看板重画为直角外框、四个等宽列和卡片短线，去掉旧的悬挂导轨及定位角。两枚图标均保持 28px、1.3px 线宽并始终静止。完整左窗与两枚按钮接力切换，窗头不为按钮留空。`bp-left` 保留 540ms 几何过渡，`bp-left-panel` 裁住会话；`bp-view-reveal` 固定在 B 旁，宽 100px，`bp-view-tools` 整组平移 100px 进出 B 后方，图标内部不动。展开时先滑回按钮（300ms），晚 180ms 伸展窗体；收起时立即回缩窗体，晚 180ms 滑出按钮（360ms），同在 540ms 收口。`data-motion` 只编排这段接力，短计时器清掉标记，卸载／反向时清理；中途反向不再等待，CSS 从当前进度返回。减少动态效果时直接切换。右侧停靠时滑动方向镜像、按钮排在 B 的左边，继续调用原 `setBlueprintView`，切视图保持左窗收起。看板标题放在视图按钮右侧，与 50px 按钮同排居中，不占四列内容区；右侧停靠时沿控件组镜像，避免越出窗口。左窗调宽／高抓手放在边内，避免被窗壳裁掉而把拖动交给图纸。背景槽位传当前窗态 `leftOpen`／`leftWidth`／`leftSide`，图纸镜头与看板均按当前停靠侧让位；拖动过程中不推动图纸，松手后更新。

竖栏底部只留 46px 高的原生设置入口，原「会话」按钮与整个侧栏板块从主界面撤下。`常驻设置.js` 经公开 entries/subscribe 装饰 `sidebar.settings`，以 React portal 移到末格；`sidebar` 的 store、inject 与子槽仍由 dsh 保留，呈现只留设置 owner。工作区浏览器按需放到项目弹窗的「全部会话」，不在主界面隐藏挂载旧列表。原生设置图标、状态、快捷键、弹窗和卸载还原沿用。
